- **Q1**: $15,000 (validazione)
- **Q2-Q4**: $90,000 ($10K/mese)
- **Totale**: $105,000

### Allocation $BX
- **Pre-Launch Contributors**: 1.78% (~18M $BX)

- **Future Development**: 38.22% (382M $BX) - Founder controlla

### Pre-Launch Price
- **$0.01 per $BX** (80% discount da target $0.05)
